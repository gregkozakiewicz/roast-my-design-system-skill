# Changelog

The skill edition has its own version. It changes when the skill's instructions change, not when the engine does; the skill always runs the latest published engine from npm.

## 1.0.0 — 2026-11-07

First release. One skill, `roast-my-design-system`, that runs the published scanner from npm and delivers the roast, the report and the rules file. Manifests for Claude Code and Codex, a marketplace file for each, and the Roast mark as the icon. Nothing in the plugin runs on its own.
